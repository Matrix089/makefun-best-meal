A tiny Python program that writes one original sentence about the best meal ever had — a $3 bowl of beef noodles at a Taipei night market, eaten standing in the rain — to /output/entry.txt for make.fun's The Best Meal You Ever Had bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
